## 🔧 Option 2: Build Yourself (15 MINUTES)

### **Prerequisites** (Install once)

**Windows:**
1. Download Node.js: https://nodejs.org/ (LTS version)
2. Download Java JDK: https://www.oracle.com/java/technologies/downloads/
3. Download Android Studio: https://developer.android.com/studio

**Mac:**
1. Download Node.js: https://nodejs.org/
2. Run: `xcode-select --install`
3. Download Android Studio: https://developer.android.com/studio

**Linux:**
```bash
sudo apt-get install nodejs npm openjdk-11-jdk
# Download Android Studio: https://developer.android.com/studio
```

### **Build Steps**

**Windows:**
1. Download repo: https://github.com/korede747/mobile-military-force-game/archive/refs/heads/main.zip
2. Extract ZIP
3. Double-click `build.bat`
4. Wait for completion
5. APK created in `military-game/platforms/android/app/build/outputs/apk/release/`

**Mac/Linux:**
1. Download repo: https://github.com/korede747/mobile-military-force-game/archive/refs/heads/main.zip
2. Extract ZIP
3. Open Terminal in folder
4. Run: `chmod +x build.sh && ./build.sh`
5. Wait for completion
6. APK created in `military-game/platforms/android/app/build/outputs/apk/release/`

### **Install on Phone**

**With USB Cable (Recommended):**
```bash
cordova run android --device
```
- Connects automatically
- Installs and launches game
- ✅ Done!

**Manual Installation:**
1. Copy APK to phone (USB or email)
2. Tap APK file on phone
3. Tap "Install"
4. ✅ Done!

✅ **Time: 15-20 minutes**
✅ **Full control**
✅ **Customizable**

## 📞 NEED HELP?

**APK won't install?**
- Enable "Unknown Sources": Settings → Apps → Allow Installation from Unknown Sources
- Check Android version (5.0+)
- Uninstall old version first

**Can't find Developer Options?**
- Tap "Build Number" 7 times in Settings → About Phone
- Developer Options will appear

**Java not found?**
- Download from: https://www.oracle.com/java/technologies/downloads/
- Set JAVA_HOME environment variable

**Cordova error?**
- Run: `npm install -g cordova`
